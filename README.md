# Iron Peak Fitness – Gym Website

A modern, responsive gym website built with HTML, CSS and JavaScript.

**Live site:** https://ironpeak-ikansh.netlify.app

## Features
- Monthly / yearly membership plan switch
- Day-wise class timetable that opens on today's day
- Trainer profiles
- BMI calculator
- Free-trial booking form
- Fully mobile-friendly

*Concept project by Ikansh — web designer & developer.*
